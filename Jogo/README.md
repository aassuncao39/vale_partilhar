# README.md

## 🗺️ GeoQuest: Mapping Our World

A self-contained, browser-based mini-game that teaches core GIS concepts to teens:

- **Vector vs Raster**
- **Geoprocessing**: Buffer, Clip, Intersect
- **Selection**: Click and polygon select
- **Raster reading**: Avoid low “NDVI” areas

No build step. All client-side with **Leaflet** + **Turf.js**.
