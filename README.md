
# 📍 Curso: Uma Introdução ao QGIS

## 📘 Ementa

Este curso aborda:

- Teoria e aplicação de Sistemas de Informação Geográfica (SIG)
- Interface do programa QGIS
- Tipos e fontes de dados
- Sistemas de coordenadas de referência
- Tabela de atributos
- Georreferenciamento e simbologia
- Criação de arquivos vetoriais
- Compositor de imagem
- Operações vetoriais e matriciais, uniões e filtros
- Webservices

## 🎯 Objetivo Geral

Apresentar o potencial de aplicação do ambiente QGIS como ferramenta de apoio à cartografia temática, voltada ao mapeamento físico-socio-territorial.

## 🎯 Objetivos Específicos

- Compreender a teoria do SIG aplicada ao mapeamento geofísico e geológico
- Navegar e utilizar a interface do QGIS de forma eficiente
- Identificar e utilizar diferentes tipos e fontes de dados
- Dominar sistemas de coordenadas de referência
- Gerenciar tabelas de atributos no QGIS
- Realizar georreferenciamento de dados espaciais
- Aplicar simbologia adequada para representação de dados
- Criar arquivos vetoriais para camadas de mapas
- Utilizar o compositor de imagem para criação de mapas
- Executar operações vetoriais e matriciais com eficiência
